# IEEE ICC occupancy paper

`icc_multimodal.tex` is the editable two-column IEEEtran source; `icc_multimodal.pdf` is the compiled five-page paper. Its vector figures are in `icc_assets/`, so the source is self-contained. Figure 4 is the validation/test model comparison without a target line. The former time-series/map Figure 5 has been removed; the new Figure 5 traces logged CSI/radar data through descriptors, frozen models, validation cutoffs, and the LLM prompt. `icc_assets/explainability_signals.pdf` is a companion visual of the six examples in Table II, including CSI packet amplitudes, logged radar RD maps, and RE temporal-variability maps. The full SHAP chart is also included as a companion figure; the paper uses a compact SHAP table. Compile from this directory with `pdflatex -interaction=nonstopmode -halt-on-error icc_multimodal.tex` twice.

The primary results are in `E2/outputs/frozen/selection.json` and `E2/outputs/frozen/evaluation.json`. Training data fit all models, missing-value medians, and scalers. Validation-minute AUC selects models; validation labels fix probability thresholds. These choices were saved before opening the multilink test features. No test-batch calibration or normalization is used. `E2/frozen_evaluation.py`, `E2/frozen_shap.py`, and `E2/llm_full_frozen.py` reproduce the figures and full-cohort language-model evaluation.

Validation and multilink test each contain both occupancy classes. The test has four held-out captures, two per class; each capture has one label. The reported accuracy evaluates those recordings with training-fitted models and validation-fixed thresholds. Minutes within a capture are correlated, and this protocol does not test occupancy transitions within a capture. Earlier exploratory work inspected the test cohort; additional independent captures would strengthen a confirmatory estimate. `NEXT_CAPTURE_PROTOCOL.md` proposes an extension that also measures transitions.

`LLM_20PCT_PROTOCOL.md`, `REVIEW_RESPONSE.md`, and `METHODS_SUPPLEMENT.md` document earlier exploration and methods review. The 20% LLM pilot and its batch ranks are superseded by the full-cohort frozen evaluation and are not reported as primary results.

The separate six-example LLM explanation check is reproducible with `E2/prepare_llm_explanations.py`, `E2/run_llm_explanations.py`, `E2/export_explainability_rows.py`, and `E2/plot_explanation_samples.py`. `E2/outputs/frozen/llm/explainability_selection.csv` holds the local labels and capture IDs; neither is sent in the API request. `explainability_request.json` holds the nonsecret prompt data, and `explainability_gpt-4o-mini.json` and `explainability_gpt-5.4.json` hold the concise responses printed verbatim in Table II. The `_detailed.json` files retain an earlier, longer explanation prompt for audit; its answers are not used in the paper or the frozen full-cohort accuracy.
